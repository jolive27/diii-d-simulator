How the agents work

The Director assigns work to separate agent lanes. Physics specifies the science, Software implements approved work, Validation tests it independently, and an outside auditor grades each stage's evidence before it can advance. Files and reports carry their work between sessions. They are development tools, not part of the simulator.

When to use a stronger model

Routine implementation and test runs are fine on a mid-tier model. Use a stronger one for analytic derivations, unexplained convergence or conservation failures, experimental equilibrium comparisons, and radial transport design.

This is an educational model. Passing numerical tests does not make it experimentally accurate.
