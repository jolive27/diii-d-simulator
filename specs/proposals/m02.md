## Evidence and mathematical benchmark

Primary scientific source read on 2026-09-06: Haolong Li and Ping Zhu, *Solving the Grad-Shafranov equation using spectral elements for tokamak equilibrium with toroidal rotation*, [arXiv:1906.05534v1](https://arxiv.org/pdf/1906.05534), Section 3.1 equations 10–16. Their static limit supplies a quartic radial plus quadratic vertical Solov’ev solution. We use our own SI/sign derivation below and do not copy inconsistent printed current signs or import their rotation model. Their rectangular prescribed-boundary benchmark supports the type of numerical test, not our chosen tolerances or experimental validation. Existing engine/test files were inspected; no new production or test implementation has occurred in this proposal.

Use coordinates in metres, psi in Wb per radian (radian dimensionless), and `Delta*=dRR-(1/R)dR+dZZ`. Let `alpha=mu0 A=0.4 Wb/m^4`, `B=0.2 Wb/m^2`, `Ra=1.66 m`, `psi_axis=0.5 Wb`. Define

`psi_exact(R,Z)=psi_axis-alpha/8*(R^2-Ra^2)^2-B/2*Z^2`.

Then `psi_R=-alpha/2*R*(R^2-Ra^2)`, `psi_RR=-alpha/2*(3R^2-Ra^2)`, `psi_ZZ=-B`, and thus `Delta*psi=-alpha R^2-B=-mu0 R^2 A-B`. Both derivatives vanish at `(Ra,0)`; Hessian there is diagonal `(-alpha Ra^2,-B)`, a strict maximum. `A=alpha/mu0` has units Pa/Wb. Set `p=A psi`, `jphi=A R+B/(mu0 R)` in A/m² and `F^2=(1.66*2)^2+2B psi` in T²m², all in M01's positive-current convention.

Crucially, the existing central stencil obeys `L_h(R^4)=8R^2-2*dR^2`; therefore `L_h psi_exact+alpha R^2+B=alpha*dR^2/4`, not zero. This quartic gives genuine second-order discretization error; do not replace it with an exactly represented quadratic. Verify this identity independently in the test harness, relative error <=1e-6 against `alpha*dR²/4` at every interior cell on all three meshes (cancellation is small but finite). This assertion detects an accidental exact-stencil benchmark.

Computational rectangle: `[1.00,2.32] m × [-0.66,0.66] m`, n=33,65,129. Every non-edge node is active; all four outer edges hold the exact, nonconstant Dirichlet values. The rectangle is a verification domain, **not an LCFS or new plasma shape model**. Its corners and edges generally have positive pressure/flux. Do not pass these nonzero-boundary basis data through the current zero-boundary current/mean-pressure algebra in `equilibrium`.

## Required production path and compatibility

The analytic test must exercise the same production finite-difference operator, SOR update and convergence mechanism used by `basis`. No independently implemented numerical solver qualifies. A minimal option on the existing basis solve is preferred: optional prescribed arrays for u and v on inactive nodes, with the old zero default. For this fixture choose

`u_exact=psi_axis/A-mu0/8*(R²-Ra²)²`, `v_exact=-Z²/2`;

then `A*u_exact+B*v_exact=psi_exact` and the individual sources remain the existing `-mu0 R²` and `-1`. Initialize only inactive boundary values; interior initialization remains zero. Source equations, iteration order, arithmetic ordering, relaxation factor, tolerances, default shape and mask must remain unchanged. If a shared production kernel is extracted instead, the default route and analytic route must demonstrably call that same kernel and pass exact M01 regression. Merely copying the stencil into a new solver is insufficient.

Validate optional boundary array dimensions and finiteness; never reinterpret default geometry or enlarge supported mesh beyond 129. An optional tighter solve tolerance may be proposed separately only if current 1e-8 residual proves insufficient to resolve the locked discretization thresholds; do not silently change it. Supply source-path evidence in the report showing the actual common production call path. Defaults and default return values must stay exactly unchanged.

## Locked analytic metrics

At all interior nodes define `Einf=max|psi_num-psi_exact|/0.5` and `E2=sqrt(sum(2pi R dR dZ error²)/sum(2pi R dR dZ))/0.5`. Include nonzero boundary values in finite differences. Require positive finite errors, and for both norms each adjacent refinement order `log2(E_n/E_2n-1)` in **[1.7,2.3]**. At n=129 require **Einf<=2e-4, E2<=1e-4**. Production normalized basis residual must be **<1e-8** on every mesh. Report all three mesh metrics and orders, never only a passing boolean.

Boundary mismatch: **max error/0.5<=1e-14** on all four edges. Report exact rectangle extrema; no LCFS error is applicable. Axis: use the grid maximum plus separate three-point quadratic vertex interpolation along R and Z through that node, not an optimizer fed the analytic axis. Require n=129 radial and vertical coordinate errors each **<=0.25 grid spacing**, and interpolated peak error/0.5 **<=2e-4**. Report both grid and interpolated estimates. Do not impose an axis-order test on symmetry-exact or roundoff-zero errors.

Pressure reconstruction `p_num=A psi_num` has max error normalized by `A*0.5` **<=2e-4** on n=129; this is a useful conversion check, explicitly algebraically dependent on flux. Current must have two paths: analytic `A R+B/(mu0 R)` and an independently written central derivative of the **numerical** psi, `j_num=-[psi_RR-psi_R/R+psi_ZZ]/(mu0 R)`. Max error normalized by max analytic current must be **<=2e-7**. This latter near-zero error is a source-equation residual check, not evidence that derivative truncation vanished. Also report the nonzero derivative error obtained by applying that test stencil to exact psi, with order **[1.7,2.3]** and matching the derived `-alpha*dR²/(4mu0 R)` within the identity tolerance above.

Use independent composite trapezoidal quadrature on the complete rectangle, distinct from M01 masked cell integration. Exact current integral is `2Zmax*[A/2*(Rmax²-Rmin²)+(B/mu0)*ln(Rmax/Rmin)]`. At n=129 require relative integrated-current error **<=1e-4** and decreasing error with refinement. Compute exact pressure mean by integrating `R psi_exact` analytically (polynomial antiderivatives), normalized by exact rectangular toroidal volume `2pi*(2Zmax)*(Rmax²-Rmin²)/2`; require numerical mean-pressure relative error **<=3e-4** at n=129 and decreasing error. This independent integral must not use solver C,D,ubar,vbar as its expected result.

## Separate shaped-mask convergence study

Use the unchanged `geometry`, `basis`, `equilibrium` with DEFAULT controls on 33,65,129, holding the **same fixed** target `Ip=1.2 MA`, `Bt=2 T`, `pbar=30000 Pa` on every mesh. Repeat for `delta=0` with otherwise identical controls. Do not rerun a grid-dependent thermal shot to set pressure. Require valid equilibria, positive finite flux/F², currentError and pressureError **<1e-11**, residual **<1e-7**, and exact zero outside-mask flux.

Record volume, peak flux, grid axis location, A/B, integrated current/mean pressure, and geometry extents at every grid. For 65→129 require relative volume change **<=3%**, peak-flux change **<=8%**, and axis displacement **<=2 times the 65-grid cell diagonal**. Ellipse n=129 volume must agree with `2pi² R0 a² kappa` to **<=0.5%**. Evaluate a dense exact parametric boundary and the staircase interface represented by active/inactive grid links; require each sampled boundary point to lie within **2 grid diagonals** of that interface and each interface link midpoint within **2 grid diagonals** of the dense curve. Use at least 4096 curve intervals. Label this discretized boundary-distance diagnostic; it does not imply LCFS contour accuracy.

For flux/volume differences report coarse-to-medium and medium-to-fine ratios and observed order when finite and nonzero, but **do not gate a global second-order rate**. Staircase masks can converge at lower order and nonmonotonically. These modest refinement gates are numerical consistency evidence only, not a manufactured analytic validation of shaped equilibria. Failure of a locked gate triggers a Director change request, not retrospective threshold relaxation.

## Independent particle/electron/ion ledgers

Permit an optional observer as the last optional runShot argument or options parameter, default disabled. It records immutable scalar snapshots for every actual step: step index, time, actual dt, pre/post N,We,Wi, and initial values/volume. No extra fields are added to the default Shot return. It must not change arithmetic, physical rates, state, timing, exceptions or default output. Observer-on and observer-off results must be deeply identical. Validate exact observer count, adjacent-state continuity, step/time continuity and initial/final coverage before trusting any budgets. Snapshot mutation must not affect simulation state or subsequent runs. If snapshots are frozen, the test must catch its own mutation exception; callback exceptions otherwise propagate without being suppressed (observer-disabled behavior remains untouched).

Tests must recompute all fluxes independently from pre-step snapshots and the declared control waveform/constants; they must **not** trust runShot energyError/particleError, its accumulated ledgers, a supplied net increment, or reuse production rates/educationalTransport to form the expected budgets. Reimplement the documented formulas in a test-only oracle with literal independently checked unit conversions; cross-check constants against the manifest. For controlled-closure tests use explicitly specified constant closure values so the expected rates are known. For each step and cumulatively compare:

`deltaN=dt*(Sgas+Sbeam-N/tauP)`;
`deltaWe=dt*(Pe+Pohm-We/tauE-Pbr-Pion-Qei)`;
`deltaWi=dt*(Pi-Wi/tauE+Qei)`.

Normalize each species error by max(initial inventory, sum absolute contributions accumulated to that point); local errors use max(pre-step inventory, sum absolute step contributions). Require **<=1e-12** for N, We and Wi individually and for combined thermal energy, on every step. Separately verify exchange contributes equal/opposite signs and magnitude. Store component ledger totals, worst error and its time. Assertions on combined energy alone are insufficient.

Required deterministic cases: DEFAULT; no NBI with default gas/ECH; no gas with default heating; increased NBI 8 MW; increased gas 5; all auxiliary heating/gas zero. Run each with dt=0.002 and 0.001 s; expected valid states or a declared explicit failure must be reported, never skipped. All listed ordinary cases are expected to complete under M01. Add an analytic continuous particle oracle with nbi=0: `N(t)=N0 exp(-t/1.6)+Sgas*1.6*(1-exp(-t/1.6))`, requiring final relative error **<=0.002** at dt=.002, decreasing under halving.

Anti-tautology check: modify COPIES of observer traces by (a) adding 1e-5 of initial N to a post-step particle state and (b) transferring 1e-5 of initial We from ion to electron post-step energy, conserving their sum. The independent validator must reject both, and specifically reject both species in (b) despite zero combined-energy discrepancy. Add source/units oracle checks for gas, beam, absorbed NBI partition and ECH using hand-calculated single-step expectations; source rates cannot be inferred from observed increments. Never mutate production state for this negative check.

## Exact regression, time refinement and stability

Before editing production, capture deterministic M01 fixtures from the original engine, with source SHA-256 and runtime version. Compare DEFAULT and the six listed case variants (deduplicate DEFAULT) at their default step, including geometry/basis arrays, residual and iteration count, shot fields/samples and selected equilibria at t=0,1,2.5,4,5. Same-runtime regression requires exact numeric equality (`Object.is` for numbers) and same object field sets, not tolerance rounding. No timestamps in fixtures. Prior fixtures must not be regenerated by the changed engine to make a failure pass. Existing nine tests, typecheck and production build remain required. Export schema stays 1, runtime physics model remains 0.1.0. Source hash may change because of instrumentation; parameter/assumption changes are prohibited.

For DEFAULT and zero-auxiliary/zero-gas formed plasma, run dt=.004,.002,.001,.0005 s; all heating switch times align. Compare N,We,Wi,Te,Ti at 0.5,1,2,2.5,3,4,4.5,5 s using actual step observations, not nearest samples. Require positive finite state, and each component's maximum normalized difference between .001/.0005 **<=1%**, normalized by max(abs finer value, 1e-12 in that component's units). For each component compute differences across these checkpoints as a vector norm and observe first-order self-convergence: ratios .004/.002 versus .002/.001 and .002/.001 versus .001/.0005 must each give order **[0.7,1.3]** unless both differences are <=1e-10 relative (report roundoff-limited, not invented order).

Stability here is numerical state validity, not plasma MHD stability. Baseline sweep dt=.01,.005,.002,.001 must complete positively with independent ledger errors <=1e-12; compare .01 to .001 at common checkpoints and require N,We,Wi relative differences **<=10%**. Inject a test-only constant closure `tauE=1e-4 s,tauP=1.6 s,resistivity=2.8e-8 ohm m` at dt=.002 to force an explicit invalid thermal step; require a throw, no clipping and no fabricated valid shot. Add dt=0,negative,NaN,.010001 invalid-input checks. This deliberately stiff closure is a guard test, not an authorized production assumption. Also run a non-event-aligned requested dt=.003: require actual dt=5/round(5/.003), correct left-endpoint heating/current logic at every observed step, exact final coverage, no fabricated samples at switch times, and independent ledgers <=1e-12. Do not impose aligned convergence orders on this run. No claim of stability for every control combination follows.
